# 研究任务

以 2026-07-15 为信息截止日，对 Visa 与 Mastercard 进行公司与组织层、产业与市场层竞品分析。仅比较这两家公司。公司与组织层固定包含通用必选维度 `positioning_strategy`、`business_model`、`go_to_market`、`operations_capabilities`、`partnerships_ecosystem`，并额外重点覆盖商业模式、网络与覆盖、财务与规模；产业与市场层固定包含通用必选维度 `market_size_growth`、`customer_segments_demand`、`competitive_landscape`、`regulation_standards`、`trends_risks`，并额外重点覆盖市场结构、监管环境。财务数字必须注明期间与口径，证据不足时输出 Unknown。
