# 研究任务

以 2026-07-15 为信息截止日，对 UPS 与 FedEx 进行产品与服务层、公司与组织层竞品分析。产品与服务层固定包含通用必选维度 `capabilities`、`pricing`、`user_experience`、`technology_integrations`、`service_support`，并额外重点覆盖服务组合、网络覆盖、客户体验；公司与组织层固定包含通用必选维度 `positioning_strategy`、`business_model`、`go_to_market`、`operations_capabilities`、`partnerships_ecosystem`，并额外重点覆盖商业模式、运营效率、财务与规模。仅比较 UPS 与 FedEx，所有时效、覆盖与财务结论均须说明来源和口径。
