# 研究任务

以 2026-07-15 为信息截止日，对 Tesla Supercharger 与 IONITY 进行产品与服务层、产业与市场层竞品分析。产品与服务层固定包含通用必选维度 `capabilities`、`pricing`、`user_experience`、`technology_integrations`、`service_support`，并额外重点覆盖网络覆盖、充电与兼容性、定价机制、用户体验；产业与市场层固定包含通用必选维度 `market_size_growth`、`customer_segments_demand`、`competitive_landscape`、`regulation_standards`、`trends_risks`，并额外重点覆盖基础设施竞争、监管与标准。地区、车型和接口差异须单独标注。
