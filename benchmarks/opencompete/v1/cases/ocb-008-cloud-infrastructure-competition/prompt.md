# 研究任务

以 2026-07-15 为信息截止日，对 Amazon Web Services、Microsoft Azure、Google Cloud 三个对象及全球云基础设施竞争格局进行通用竞品分析。公司与组织层固定包含通用必选维度 `positioning_strategy`、`business_model`、`go_to_market`、`operations_capabilities`、`partnerships_ecosystem`，并额外重点覆盖商业模式、产品生态、财务披露；产业与市场层固定包含通用必选维度 `market_size_growth`、`customer_segments_demand`、`competitive_landscape`、`regulation_standards`、`trends_risks`，并额外重点覆盖市场结构、竞争动态、监管与主权云。不得增加其他云厂商为核心比较对象，第三方数据必须说明定义和口径。
