# 研究任务

你是平台工程负责人，需要为一家中型 SaaS 企业确定未来 24 个月默认采用的事件驱动计算平台。以 2026-07-17 为信息截止日，只比较 AWS Lambda 与 Azure Functions，不增加其他云函数产品。

报告必须覆盖突发型 HTTP API、消息与文件异步处理、延迟敏感型常驻容量、有状态工作流四类场景，并比较：核心能力、托管与扩缩容模型、运行限制、可靠性与 SLA、网络安全、可观测性与治理、生态集成、支持、同口径总成本以及迁移锁定。

价格只有在地区、币种、日期、请求量、内存、执行时长、并发和常驻容量都一致时才能比较。没有冻结价格快照、企业折扣或相同负载实测时，成本、冷启动、吞吐和开发效率必须写为 Unknown。

最终报告必须给出：

1. 面向评审委员会的一页决策摘要；
2. 四类工作负载的条件化选择矩阵；
3. 关键事实、口径差异与证据边界；
4. 不建议场景和淘汰条件；
5. 一个最小 PoC 与成本验证计划。
