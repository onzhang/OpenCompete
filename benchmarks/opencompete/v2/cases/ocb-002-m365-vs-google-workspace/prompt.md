# 研究任务

你是 250 人美国混合办公知识型企业的 CIO，需要选择未来三年的标准协作套件，并判断迁移是否值得。以 2026-07-17 为信息截止日，只比较 Microsoft 365 与 Google Workspace。

报告必须先映射等价 SKU，再比较企业邮箱、会议、文档与文件协作、桌面和浏览器工作流、身份、设备、安全、DLP、保留、电子发现、审计、数据区域、AI 权益与治理、支持与 SLA、迁移工具、双轨期和三年总成本。

必须分别讨论：Windows/Office 重度组织、浏览器优先分布式团队、受监管组织。价格只有在地区、币种、合同期限、席位数和附加许可一致时才能比较。没有冻结价格、租户测试或迁移盘点时，生产率、安全效果、迁移工时和 TCO 胜者必须写为 Unknown。

最终交付应包含条件化建议、不建议场景、迁移尽调清单和 30–60 天试点方案。
