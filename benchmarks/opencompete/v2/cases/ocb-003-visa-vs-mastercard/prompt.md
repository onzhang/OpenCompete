# 研究任务

你是计划在北美和欧洲推出跨境消费者及中小企业卡产品的支付 FinTech 战略负责人。以 2026-07-17 为信息截止日，只比较 Visa 与 Mastercard，目标是确定主要网络、第二网络和增值服务合作策略。

报告必须覆盖：四方网络商业模式、收入驱动、网络规模及指标定义、财务规模、合作生态、欺诈/身份/数据/开放金融等增值服务、网络效应、方案费与议价、美国借记路由、英国方案和处理费监管、欧洲支付结构、实时账户支付与其他替代轨道。

必须区分公司披露、监管机构最终结论、司法诉讼指控和分析判断。支付量、GDV、processed/switched transactions、卡片、凭证和受理点不得在定义不同的情况下直接排名。公开资料不足的客户费率、返利、最低承诺、授权率、欺诈率、争议处理和合同 SLA 必须写为 Unknown。

最终报告不得宣布无条件唯一胜者，而应给出地区和产品场景建议、双网络 RFP、尽调问题、PoC 指标与淘汰门槛。
