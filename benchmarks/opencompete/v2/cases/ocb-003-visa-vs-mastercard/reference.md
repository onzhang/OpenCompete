# Visa 与 Mastercard 跨境发卡网络合作策略参考报告

> 专家状态：本 Reference 已由两个独立 AI 支付行业竞品分析专家角色完成作者与复核闭环，未经过人类审核。公司规模数字尚未冻结为可审计事实，客户实际商业条款和运行质量也不公开，不能据此宣布唯一网络胜者。
>
> Reference 模式：`mixed`。可冻结的监管原文作为事实锚点；未固定的公司交易、份额和客户级结果均保持 Unknown。

## 1. 决策摘要

Visa 与 Mastercard 都应进入候选集，但当前未冻结双方具体 2025 Form 10-K，不能把公司收入、交易和网络规模数字写成可审计金标准。[visa-annual-report] [visa-sec-filings] [mastercard-annual-reports] [mastercard-sec-filings]

对跨境发卡 FinTech，公开资料最可靠的结论不是“谁规模更大就选谁”，而是两家公司都应进入双网络 RFP。最终主要网络应由目标市场的净费率与返利、受理和授权表现、欺诈与争议处理、数字钱包和代币化、数据与身份服务、实施周期、支持 SLA 及监管约束决定。这些关键商业与运营数据大多不公开，因此当前唯一网络选择为 **Unknown**。

## 2. 商业模式与网络规模

双方年报和 SEC 发行人入口只能用于定位法定文件；本数据集尚未固定具体 2025 Form 10-K accession、文件哈希和页码。因此，双方精确净收入、支付量/GDV 和 processed/switched transactions 在本 Benchmark 中保持 **Unknown**。[visa-annual-report] [mastercard-annual-reports] [visa-sec-filings] [mastercard-sec-filings]

即使后续固定文件，这些数字也不能直接转换为市场份额或合作质量：Visa 与 Mastercard 的财年截止日不同，支付量与 GDV、processed 与 switched、凭证与卡片都有不同定义、时点和排除项。成熟报告必须保留原始定义，而不是制作看似精确的统一排名。

## 3. 增值服务与合作适配

合作评估应拆成网络接入、第二网络/路由和增值服务三个采购包：主要网络不应自动获得全部欺诈、身份或数据服务，FinTech 应按 API、覆盖地区、模型效果、数据权利、成本和退出能力分别评估。

公开年报能证明战略方向和服务类别，不能证明相同客户项目中的欺诈降低、授权提升或实施效率。相关效果在 PoC 前为 Unknown。

## 4. 市场结构、费用与监管

英国 Payment Systems Regulator 已发布卡方案和处理费市场审查最终报告。[psr-scheme-fees-final] 本案例只冻结了报告页面标题，未把报告正文结论做成 direct quote，因此不以该标题单独推导竞争强度、费用涨幅或全球结论；RFP 仍应把英国方案费、处理费、费用透明度和变更机制列为尽调重点。

美国 Regulation II 对借记交换费合理性与成本相称性建立标准，允许符合条件的欺诈预防调整，并禁止把可处理网络限制为少于两个非关联网络或妨碍商户在已启用网络间选择路由。[federal-reserve-regulation-ii] 这些规则使北美借记产品不能只做品牌选择，还必须做发行人、网络关联性和路由设计审查。美国司法部已起诉 Visa，页面标题表达的是政府垄断主张，不是最终裁判。[doj-visa-debit-case]

ECB 支付统计说明欧洲支付体系包含卡、转账、直接借记等多种工具。[ecb-payment-statistics] 实时账户支付、数字钱包和本地基础设施可能改变部分交易路由，但当前固定资料不能量化它们分别从 Visa 或 Mastercard 转移了多少份额。

## 5. 场景化合作建议

| 场景 | 重点 | 建议 |
|---|---|---|
| 北美借记 | Regulation II、路由、费率、授权和本地网络要求 | 双网络与路由方案并行评估；法律和合规团队参与 RFP |
| 欧洲跨境 | 方案/处理费、透明度、消费者保护、替代支付轨道 | 要求费用可解释、变更通知和监管配合条款；不得用全球规模代替欧洲经济性 |
| 高跨境占比 | 汇率、跨境费用、受理、争议和欺诈 | 使用真实交易样本比较净经济性与授权表现 |
| 增值服务采购 | 代币化、身份、欺诈、数据、开放金融 | 与网络合同解耦评分，保留替换和数据退出能力 |

## 6. RFP 与 PoC

RFP 至少要求双方提供：目标国家和 MCC 的净费率及返利模型、最低承诺、三年费用变更机制、数字钱包和代币化覆盖、授权和欺诈基准定义、争议处理、实施资源、生产支持 SLA、数据使用权、审计、监管变更和退出条款。

财务与网络规模附件必须使用口径字典：分别记录公司财年起止、指标原名、是否含境内/跨境、是否含现金、是否按交易笔数或金额、卡片还是凭证、期末还是期间平均。只有同财务期间、同网络范围、同排除项的数据才允许并排；否则只能保留原值和“不可比”标签，禁止计算全球份额。

PoC 应使用相同商户类别、国家、卡产品和交易样本，记录授权率、软拒绝恢复、欺诈损失、误拒、争议周期、令牌化成功率、API 可用性、实施工时和总成本。任何一方未提供可审计指标、费用不可解释或退出条款不可接受，都应成为淘汰条件。

风险委员会应在报价揭盲前冻结权重与门槛。监管或路由不合格属于一票否决；其余项目按风险调整净成本、授权/欺诈、实施与支持、数据权利和退出能力评分。若两方差异低于预设显著性门槛，则保留双网络或分地区配置，而不是制造单一胜者。

## 7. 不建议场景与 Unknown

- 不建议用净收入、支付量、GDV、交易数或覆盖国家数单一指标选择网络。
- 不建议把监管机构对某一区域的结论外推为全球结论。
- 不建议把 DOJ 诉讼指控写成已经判决。
- 客户实际费率、返利、授权率、欺诈表现、争议质量、实施周期和合同 SLA 均为 Unknown，必须通过 RFP、合同尽调和 PoC 关闭。
- 若业务允许，保留第二网络和替代支付轨道可降低单一网络、费用变化和区域监管风险；具体收益仍需合同数据验证。
