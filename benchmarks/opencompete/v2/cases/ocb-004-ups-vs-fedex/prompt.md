# 研究任务

你是美国中型 DTC 零售企业的物流与采购顾问。企业未来 12 个月预计发送约 25 万件包裹，其中 70% 为美国住宅陆运、20% 为两日达、10% 为美国发出的跨境件，并存在明显旺季波动。

请比较 UPS 与 FedEx，帮助决策者选择主要承运商，并判断是否应保留第二承运商。报告必须覆盖服务组合、网络与运营能力、情景总成本、可靠性与服务保证、异常处理与理赔、技术集成、迁移成本、公司经营变化对供应连续性的影响。

公开牌价不等于企业协议价。没有同日期、同路线、同重量尺寸、同住宅属性和同服务等级的报价时，不得判断谁更便宜；没有同条件独立运营数据时，不得判断谁更准时或更可靠。财务年度、公司口径和业务分部必须明确区分。无法核验的信息写作 `Unknown`。

最终建议必须按适用条件表达，至少给出：优先 UPS、优先 FedEx、采用双承运商以及不应立即作出选择的场景。
