# UPS 与 FedEx 主承运商决策参考报告

## 一、决策结论

这家美国中型 DTC 企业不应按品牌或公司规模指定唯一赢家。公开证据表明 UPS 与 FedEx 都提供美国标准配送、加速配送和国际优先服务；真正尚未解决的是本企业三类货件的完整每票成本、实际履约、异常处理、技术集成和迁移成本。

推荐采用“按服务篮子决策”：固定美国住宅 Ground、美国住宅两日达、美国至英国跨境三个 shipment basket，取得同日正式报价，完成 4 至 6 周双承运商试运行和 API POC，再分别确定主备关系。若旺季中断的预期损失高于维持第二承运商的成本，应保留双承运商；否则可对表现稳定的篮子集中采购。

## 二、可比口径

- 决策期限：未来 12 个月。
- 业务结构：年约 25 万件；70% 美国住宅陆运、20% 两日达、10% 美国发出的跨境件。
- 价格口径：同日期、路线、重量、尺寸、住宅属性、服务等级、币种、税、折扣和附加费。
- 履约口径：承诺日、实际送达日、首次投递成功、丢损、异常恢复和理赔结案。
- 财务口径：UPS 2025 是日历年；FedEx FY2025 截至 2025 年 5 月 31 日，不能当作完全同期排名。
- 网络口径：公司件量、飞机、车辆和投递点只能证明规模，不能替代目标线路表现。

## 四、竞争机制与替代解释

UPS 的公司级件量和 FedEx 的网络资源可以支持“双方均具备规模化运营能力”，但不能支持“规模更大的一方在本企业线路更可靠”。网络密度、路线结构、包裹组合、合同折扣、旺季容量和当地站点执行都会改变实际结果。

UPS 披露 Amazon 及其关联方约占 2025 年合并收入 10.6%，并计划到 2026 年 6 月把相关业务量较 2024 年减少超过 50%。[ups-2025-10k] 这可能改变部分网络密度和成本结构，但也可能提高收入质量或释放容量。缺少区域数据时，不能把它直接解释为服务恶化或改善。

FedEx 的投递点、飞机和车辆数量可能有利于触点覆盖和网络调度，但它们也可能伴随更高固定成本或不同网络分工。没有同路线运营结果时，不能把资产数量写成相对优势。

## 五、情景 TCO

当前没有双方同日、同路线、同包裹属性和同合同条件的报价，情景总成本优劣为 `Unknown`。公开页面的“预算友好”或概括时效不能替代采购成本。

三个固定篮子应采用相同发件地、收件地、日期和包裹参数。两日达篮子必须先让 FedEx 书面确认目标邮编可售产品、承诺日和保证条件，不能假定存在性：

1. 美国住宅 Ground：2 lb、12×9×4 英寸、Zone 5。
2. 美国住宅两日达：同一包裹参数与住宅属性。
3. 美国至英国跨境：2 kg、统一尺寸、申报价值和清关假设。

完整 TCO 至少包括：基础运输费、燃油附加费、住宅和偏远地区附加费、超尺寸或附加处理费、取件和退货费、理赔未覆盖损失、系统集成和迁移成本，并扣除合同折扣与服务失败退款。合同最低消费、承诺量和旺季费用应做敏感性分析。

## 六、技术集成与迁移

UPS Developer Portal 和 FedEx Developer API Catalog 均可访问，但本轮没有取得足以对齐标签、费率、追踪、地址校验、Webhook、沙箱、限流和错误恢复的稳定正文。因此，API 覆盖、实施工时和稳定性优劣为 `Unknown`。[ups-developer-portal][fedex-developer-catalog]

技术 POC 应使用同一订单集验证：

- 费率和预计送达日；
- 标签生成、取消和重打；
- 追踪事件完整性、顺序和延迟；
- 退货、地址修正和异常流程；
- 账单、附加费和对账；
- 超时、限流、重试和幂等。

迁移成本还包括地址簿、包装规则、标签模板、退货门户、理赔材料、历史追踪、客服脚本、仓库培训和账单对账。切换前应至少保留一个结算周期的双写与回滚能力。没有完成上述盘点时，任何“更容易集成”的判断都应视为无证据。

## 七、可靠性与异常处理

当前固定来源没有同线路、同服务等级、同期间的准时率、首次投递成功率、丢损率和理赔周期，因此可靠性排名为 `Unknown`。官方时效描述是产品定义，不是历史履约率。

4 至 6 周试运行应记录：每票完整成本、承诺与实际送达时间、首次投递成功、异常通知延迟、地址修正、丢损、理赔提交材料数量、结案天数和客服升级次数。试运行必须覆盖至少一个业务高峰或明确承认季节外推限制。

## 八、条件化建议

### 何时优先 UPS

若 UPS 在美国住宅 Ground 或两日达篮子的完整每票成本更低，试运行履约达到企业门槛，API POC 和账单对账通过，并且客户业务量调整没有在目标区域造成容量或服务风险，可把对应篮子交给 UPS。

### 何时优先 FedEx

若 FedEx 在住宅、加速或国际篮子的完整成本、交付表现和异常处理更优，且企业确实利用其住宅配送日、投递触点或国际优先服务，可把对应篮子交给 FedEx。

### 何时保留双承运商

若旺季停运一天即可造成显著收入、SLA 或客户流失损失，或不同服务篮子的最佳承运商不同，应保留双承运商。冗余的代价是双套集成、培训、预测和最低消费管理，必须与中断损失比较。

### 不应立即决策的场景

- 只有官网起价，没有完整报价和附加费。
- 只有服务保证，没有实际履约数据。
- 只有开发者入口，没有 API POC、双写和回滚演练。
- FedEx 两日达产品、目标邮编承诺或保证条件尚未通过正式报价确认。
- 仅用利润率、件量、飞机或投递点决定服务优劣。

## 九、结论翻转条件与补证计划

以下任何一项都可能翻转主备选择：合同折扣和最低消费、旺季附加费、目标区域容量、试运行准时率、丢损和理赔、API 错误恢复、账单差异率，以及迁移双写成本。

签约前完成顺序应为：固定篮子与门槛 → 同日报价 → API POC → 4 至 6 周双承运商试运行 → 一个结算周期账单核对 → 按篮子确定主备关系 → 保留可回滚配置。
