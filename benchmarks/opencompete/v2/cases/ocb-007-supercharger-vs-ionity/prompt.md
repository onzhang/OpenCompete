# 研究任务

以 2026-07-15 为截止日，为欧洲跨境出行用户、车队运营负责人和整车厂充电合作负责人，对 Tesla Supercharger 与 IONITY 进行决策型竞品分析。

研究必须限定在欧洲公共高功率充电，并重点覆盖德国、法国和荷兰。Tesla 车型与 CCS 非 Tesla 车型须分开；站点与充电点、已运营与在建、额定峰值与车辆实际可接受功率、按量价格与订阅价格须分别定义。动态价格、开放车型和站点状态必须注明国家、日期、账户或车型条件。

报告应分别回答：Tesla 车主高频跨境、非 Tesla 车主高频跨境、偶发公共快充用户和多车型车队应如何选择；什么条件会改变建议；签订订阅或合作协议前还需要验证什么。无法从固定来源核验的事实必须写为 **Unknown**，不得以常识或厂商营销语补齐。
