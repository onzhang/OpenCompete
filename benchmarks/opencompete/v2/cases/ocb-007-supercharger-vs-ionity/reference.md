# Tesla Supercharger 与 IONITY 欧洲跨境高功率充电决策 Reference

> Reference 模式：`evidence_scarcity_challenge`。本报告评价系统能否在来源不完整、动态网页不可冻结和双边证据不对称时，仍形成成熟的可比边界、替代解释、决策门槛与补证计划；它不是两家网络完整事实金标准，也未经过人类审核。

## 1. 决策结论

截至 2026-07-15，固定来源不足以指定 Tesla Supercharger 或 IONITY 为德国、法国和荷兰跨境补能的统一赢家。IONITY 的官方网络页能支持三项有限事实：网络被描述为覆盖欧洲 24 国、提供站点查找与实时可用性入口，并在地图中区分开放与建设中位置。[ionity-network] Tesla 的两个固定官方入口均访问受阻；两家的三国价格、目标车型兼容、实际充电曲线、启动成功率、排队和客服结果没有形成同口径证据。[tesla-supercharger] [tesla-other-ev-support] [ionity-subscriptions]

这不意味着两家真实能力相同，也不意味着 IONITY 必然更好。更窄的结论是：当前证据只能支持建立验证顺序，不能支持长期排他承诺。对年度订阅、多车型车队或整车厂合作，应先补齐逐国价格和车型规则，再用真实车辆完成代表路线试充；任一网络未达到预先冻结的覆盖、兼容、成本与启动成功门槛时，保留双网络策略。

## 4. 竞争机制与替代解释

IONITY 的跨国覆盖描述、位置状态和实时可用性入口说明其公开服务界面试图把基础设施位置与行程规划连接起来。[ionity-network] 但这条机制只有在位置覆盖目标走廊、状态数据准确、目标车型可用且启动成功时，才会转化为更好的行程结果。当前来源没有这些结果指标。

至少存在五个可能改变表面网络规模结论的替代解释：

1. 站点更多，但偏离目标高速走廊，实际绕行更长。
2. 充电点总数更多，但每站密度低，高峰排队风险更高。
3. 额定功率更高，但目标车型充电曲线无法利用峰值。
4. 按量价格较高，但订阅后对高频用户更低；对偶发用户则相反。
5. App 提供实时状态，但刷新延迟或启动失败使功能存在未转化为可靠结果。

因此，成熟竞争分析必须用路线、车型和使用频率解释差异，不能把厂商网页可访问性、网络总数或功能入口当作胜负代理。

## 5. 场景化建议

### Tesla 车主、高频跨境

在取得 Tesla 三国站点、价格和目标路线覆盖前，不能仅凭品牌生态推荐年度锁定。若试点证明车机规划、路线覆盖、实际成本和启动成功均达到门槛，可把 Tesla 设为默认；否则保留 IONITY 作为第二网络。

### 非 Tesla 车主、高频跨境

Tesla 的非 Tesla 开放规则为 Unknown。IONITY 至少有可核验的跨国网络和实时入口，但这不证明目标车型兼容或成本更优。先验证 VIN/车型资格、接口、三国价格和实际启动；任一关键国家不可用时，不应建立单网络政策。

### 偶发公共快充用户

偶发用户的订阅盈亏平衡通常不同于高频用户，但当前价格快照缺失。决策应优先当日即时价格、无需长期承诺的支付方式和备用站点，不应仅因月费折扣存在而订阅。

### 多车型车队

车队需要跨车型兼容、发票、支付控制、故障支持和可预测成本。上述字段大多 Unknown，不应采用排他网络政策。建议以两种代表车型完成德国—法国—荷兰路线试点，并保留第二网络直到连续达到覆盖、启动成功、成本和支持门槛。

### 整车厂充电合作负责人

现有固定来源不足以比较双方的漫游或 Plug & Charge 集成、车辆识别、结算、数据共享、品牌呈现、服务 SLA、区域扩张承诺和退出条款，这些合作字段均为 **Unknown**。公共消费者页面不能替代 NDA 接口材料、商务报价和合同草案。

整车厂在签订合作协议前，应分别完成接口与车辆识别 POC、三国覆盖与容量承诺核验、结算对账、数据与隐私评审、服务升级演练及退出迁移测试。任何一项关键门槛未满足时，不应签订长期排他协议；消费者路线试充通过也不能自动证明 OEM 合作能力合格。

## 6. 决策门槛与结论翻转条件

决策者应在查看测试结果前冻结门槛，例如：

- 目标路线必须有可接受绕行距离内的运营站点和备用站点。
- 所有目标车型必须明确兼容，不依赖未批准适配器。
- 同使用频率下的三国总成本不得超过预算上限。
- 启动成功、排队和故障恢复必须达到车队或个人可接受标准。
- 年度订阅或排他承诺必须可退出，且价格变更机制可接受。

若某网络同时达到以上门槛，可成为默认网络。若只有覆盖领先但价格、兼容或可靠性失败，结论不得翻转为单网络；应继续双网络。若后续固定证据证明 Tesla 在目标路线具有更高可达性且目标车型/账户价格更低，当前不排名结论可翻转为 Tesla 默认。若 IONITY 在相同条件下达到这些结果，则可翻转为 IONITY 默认。

## 7. 最小补证计划

1. 固定 Tesla IR 静态材料或三国充电地图导出，记录站点、充电点、状态和日期。
2. 在同一天保存两家德国、法国和荷兰的按量、订阅、税、漫游和占位费。
3. 使用目标车辆 VIN 或车型验证 Tesla 非 Tesla 开放和 IONITY 兼容条件。
4. 选择一条德国—法国和一条德国—荷兰路线，记录绕行、备用站、启动成功、实际功率、排队、费用和客服。
5. 固定 Official Journal AFIR 正文，按条款、日期和站点类型完成适用性矩阵。
6. 对整车厂合作，取得双方接口文档、SLA、数据治理、商务报价、覆盖承诺和退出条款，并完成对等 POC。
7. 试点结束前不调整通过门槛；保存原始日志、账单和截图以便复核。
