# 研究任务

以 2026-07-15 为截止日，为大型企业云战略、采购、架构、风险与合规负责人，对 Amazon Web Services、Microsoft Azure 和 Google Cloud 进行决策型竞争分析。

研究目标不是输出脱离工作负载的云厂商排行榜，而是判断三家在主云、数据与 AI 平台、受监管工作负载和退出敏感场景中的适用条件。财务必须注明报告期间、币种和分部边界；市场份额必须注明市场定义、地区和统计期；Region、Availability Zone、Zone、Geography 和 Location 不得混用；SLA 必须绑定具体服务和部署拓扑；价格必须使用固定区域、配置、币种、日期及折扣假设。

报告应分别回答：Microsoft 既有栈深的受监管企业、数据与 AI 原生团队、需要广泛全球基础设施的企业、以及高度关注多云和退出成本的企业，应如何形成短名单和验证计划。无法从固定来源核验的收入、份额、价格、主权云、AI 容量或可靠性事实必须写为 **Unknown**。
